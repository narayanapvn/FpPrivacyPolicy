# FinPulse – Privacy Policy & Terms website

Static website (no build step). Pages:

- `index.html` – home with big "FinPulse" heading
- `privacy-policy.html` – Privacy Policy
- `terms-and-conditions.html` – Terms & Conditions
- `data-deletion.html` – Data deletion instructions

## 1. Edit your details (important)
Search & replace in all `.html` files:

| Find | Replace with |
| --- | --- |
| `YOUR NAME` | your name / company |
| `YOUR_EMAIL@example.com` | your support email |
| `YOUR COUNTRY` and `YOUR COUNTRY / STATE` | your country (for governing law) |

## 2. Publish on GitHub Pages
1. Create a new public repository, e.g. `finpulse`.
2. Upload all files from this folder (keep the `assets` folder). Make sure `index.html` is in the root.
3. Repo → **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.
4. After ~1 minute your site is live at `https://YOUR-USERNAME.github.io/finpulse/`.

Your URLs:
- Privacy Policy: `https://YOUR-USERNAME.github.io/finpulse/privacy-policy.html`
- Terms: `https://YOUR-USERNAME.github.io/finpulse/terms-and-conditions.html`
- Data deletion: `https://YOUR-USERNAME.github.io/finpulse/data-deletion.html`

Use the Privacy Policy URL in Google Play Console, the OAuth consent screen and AdMob.
